# 首单成交作战卡（AI小程序审核合规助手）

## 目标（仅为拿下首单）
- 目标：24小时内拿到 1 条可验证成交记录（>=49元定金或99元全款）
- 对象：过去30天内有小程序提审/改版需求的开发者、外包、代运营
- 口径：先锁首单，不追求客单价最大化

## 60分钟执行节奏（可重复）
1. 0-15分钟：发送10条（5条A开场+5条B开场）
2. 15-30分钟：处理回复，10分钟内完成4问资格判断
3. 30-45分钟：仅对A/B类报价（99全款优先，49定金备选）
4. 45-60分钟：对已报价未付款线索发“截止时间+保障条款”

## 4问资格判断（10分钟内必须完成）
1. 预计提审时间（本周/下周/不确定）
2. 目前卡点（风险词/类目资质/材料不全/被驳回）
3. 是否能今天提供基础材料（截图、驳回原因、类目）
4. 本次目标（先过审/降低驳回率/加速提审）

## 快速分级
- A类：本周提审 + 有明确卡点 + 今天可给材料 -> 直接收款
- B类：有需求但材料不齐 -> 先收49定金锁档，约补料时间
- C类：时间不确定且无法配合 -> 进入培育，不占当小时主精力

## 成交推进三连
1. 报价："首单99，24小时内给完整整改单；若未按时交付，全额退。"
2. 备选："如果你想先低风险启动，可先付49定金锁档，交付后补尾款50。"
3. 截止："今晚24:00前可保留首单价和优先排期，过时恢复常规价。"

## 可验证成交记录（必须留痕）
- 联系人
- 金额（99或49）
- 凭证（截图路径/转账单号）
- 时间戳
- 线索来源（渠道+文案版本）

## 本小时底线KPI
- 发送 >= 30
- 已回复 >= 5
- 已报价 >= 3
- 待付款 >= 1
- 已付款 >= 1（首要）
