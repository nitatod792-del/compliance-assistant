# 审核合规助手 - 30条可直接发送触达清单（16:41-17:40）

## 使用说明
- 目标：把"待发"变成"可一键发送"，压缩执行准备时间到 10 分钟内。
- 发送规则：每条只改 `对象名` 与 `最近上线时间` 两个字段即可发出。
- 记录规则：发送后在状态列打 `已发`，有回复改 `已回复`，发报价改 `已报价`。

## 回复后10分钟动作
1. 先收集 4 个信息：小程序名、最近打回原因、核心功能、提审时间。
2. 判定 A/B/C：
   - A：72小时内提审 + 信息完整 -> 直接发 99 元报价。
   - B：有明确上线计划但信息缺失 -> 先补信息，2小时后二次推进。
   - C：暂无提审计划 -> 留存并约下次节点。
3. 发报价后 2 小时未回：发送一次简短催单（仅一条）。
