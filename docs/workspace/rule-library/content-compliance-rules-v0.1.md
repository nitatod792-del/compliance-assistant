# 内容审核合规规则库 v0.1

## 1. 目标与适用范围
- 目标：将审核判断标准结构化，减少主观偏差，支持后续自动化命中与复核。
- 适用范围：图文内容初审、复审、申诉复核。

## 2. 风险分级定义
- P0（禁止）：违法违规或高风险违法导向内容，必须拦截。
- P1（高风险限制）：可能触发合规风险，需要限制分发并进入人工复核。
- P2（中风险提示）：存在争议或轻度风险，可降权并抽检复核。
- P3（低风险）：基本合规，允许通过。

## 3. 规则条目（首批）
| 规则ID | 分类 | 风险级别 | 命中信号（示例） | 处理动作 | 证据要求 |
|---|---|---|---|---|---|
| CR-001 | 违法交易引导 | P0 | 明确出现交易方式、价格、联系方式并指向违法品类 | 拒绝 + 升级法务通道 | 截图 + 命中片段 + 审核人 |
| CR-002 | 暴力伤害煽动 | P0 | 鼓励/指导他人实施伤害行为 | 拒绝 + 紧急复核 | 片段定位 + 时间戳 |
| CR-003 | 仇恨歧视表达 | P1 | 针对特定群体的侮辱、煽动排斥 | 限制 + 人工复核 | 命中文本 + 上下文 |
| CR-004 | 医疗功效绝对化 | P1 | "包治"、"根治"、"100%有效" 等绝对化宣传 | 限制 + 要求修改 | 命中词 + 页面位置 |
| CR-005 | 金融收益承诺 | P1 | "稳赚"、"保本高收益"、"无风险套利" | 限制 + 复核 | 命中词 + 账号历史 |
| CR-006 | 轻度不当用语 | P2 | 低强度侮辱、擦边挑衅 | 降权 + 抽检 | 命中片段 |
| CR-007 | 信息不完整广告 | P2 | 关键免责声明缺失（价格/条件/限制） | 打回修改 | 缺失项记录 |
| CR-008 | 正常信息表达 | P3 | 无高风险信号 | 放行 | 审核结论 |

## 4. 判定优先级
1. 多规则同时命中时，按最高风险级别处理（P0 > P1 > P2 > P3）。
2. 同级别多命中时，优先执行更严格动作（拒绝 > 限制 > 降权 > 放行）。
3. 若命中证据不足，进入人工复核，不直接放行。

## 5. 复核与追踪字段（最小集）
- case_id
- content_id
- hit_rule_ids（可多选）
- risk_level
- decision（reject/restrict/downgrade/pass）
- evidence_snippet
- reviewer
- review_time
- recheck_required（Y/N）
